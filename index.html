Diseño web responsivo, explicado con ejemplos

Haz la ventana del navegador más estrecha y más ancha, y mira cómo cambia cada ejemplo. Debajo de cada demostración está el código que lo hace posible.

1. Diseño responsivo (mobile first)

Se diseña primero para el móvil y se amplía para pantallas grandes. Para que el móvil no encoja la página, el HTML lleva esta línea dentro de <head>:

<meta name="viewport" content="width=device-width, initial-scale=1">

2. Rejillas fluidas

Las cajas se reparten el ancho disponible. Con auto-fit y minmax el navegador decide cuántas columnas caben.

.rejilla {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(10rem, 1fr));
  gap: 0.75rem;
}

3. Unidades relativas (%, rem, fr)

Los tamaños no son píxeles fijos. El porcentaje depende de la caja que lo contiene y rem depende del tamaño de letra del navegador. Mueve el control y observa cómo todo se adapta.

Ancho 50 %
Ancho 20 rem (máximo 100 %)
.b1 { width: 50%; }
.b2 { width: 20rem; max-width: 100%; }
body { font-size: 1rem; }

4. Media queries

Son reglas que solo se aplican a partir de cierto ancho. Aquí hay dos puntos de corte, 700 px y 1000 px.

Columna B
Columna C
.dos-puntos { grid-template-columns: 1fr; }
@media (min-width: 700px)  { .dos-puntos { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 1000px) { .dos-puntos { grid-template-columns: repeat(3, 1fr); } }

5. Contenido adaptable

No solo cambian las columnas, también cambia la forma del contenido. El menú es vertical en móvil y horizontal en pantallas grandes, y el mensaje de abajo es distinto en cada caso.

  • Puntos de corte
  • Imágenes

nav ul { display: flex; flex-direction: column; }
@media (min-width: 700px) { nav ul { flex-direction: row; } }

6. Imágenes flexibles

Esta imagen mide 800 px de ancho, pero nunca se sale de su caja y conserva su proporción.

img { max-width: 100%; height: auto; }
